# Portfolio Website
#### A modern, responsive portfolio website built with Next.js and Tailwind CSS.

## ✨ Features
 * Responsive Design: Works on all device sizes
 * Modern UI: Clean, intuitive interface with smooth animations
 * Contact Form: Integrated with Web3Forms for easy communication
 * Project Showcase: Displays work samples with hover effects
 * Dark/Light Mode: Toggle between themes (coming soon)

## 🛠 Technologies Used

 * Next.js (App Router)
 * Tailwind CSS
 * Framer Motion (for animations)
 * Web3Forms (for contact form)
 * Next.js Image Optimization

### Sections

 #### 1. Header: Introduction with call-to-action buttons
 #### 2. About: Personal info and skills
 #### 3. Services: Offered services with descriptions
 #### 4. Work: Project portfolio showcase
 #### 5. Contact: Functional contact form
 #### 6. Footer: Social links and copyright

## 🚀 Setup Instructions
 ### 1. Clone the repository:
    git clone https://github.com/Prince13061997/Prince-portfolio.git

 ### 2. Install dependencies:
    npm install

 ### 3. Run the development server:
    npm run dev

## Customization

 * Update content in assets/assets.js
 * Modify colors in globals.css
 * Add/remove projects as needed
